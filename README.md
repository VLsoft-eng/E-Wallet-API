## Описание

E-Wallet - это аналог Qiwi кошелька. Зарегистрированные пользователи имеют возможность совершать транзакции с другими пользователями и получать информацию о движении своих денег.
Пользователь может попытать удачу с кодом hesoyam и получить 100 д.е с шансом 25%.
При переводе участники транзакции получают email-оповещение.(soon)

## Технологии

* Java 23
* Spring Boot
* Spring Data
* Spring Security
* Docker compose
* Slf4 + logback
* Apache Kafka
